# Acme DocVault API -- pinned dependencies.

# All versions are pinned EXACTLY (==) so the correlator can look each one up
# against public advisory data (OSV). The mix is deliberate, and it is what
# makes the reachability funnel tell a story:
#
#   * a few old pins are REACHABLE from a public HTTP route;
#   * exactly one of those is EXPLOITABLE (attacker input reaches its sink);
#   * several old, vulnerable pins are only reached from offline CLI/cron code
#     (or are declared-but-unused), so they are UNREACHABLE from the service.
